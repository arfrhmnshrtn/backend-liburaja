Introduction

Selamat datang di dokumentasi API Liburaja. Dokumentasi ini menyediakan informasi lengkap mengenai semua endpoint yang tersedia di backend aplikasi, parameter yang dibutuhkan, dan struktur respons.

Base URL

Base URL untuk mengakses API adalah: http://203.194.115.158:3000/api

Authentication (Otorisasi)

Sebagian besar endpoint memerlukan autentikasi menggunakan JSON Web Token (JWT). Untuk mengakses endpoint yang diproteksi, Anda harus menyertakan token dalam header permintaan (Request Header).

Authorization: Bearer <token_jwt_anda>
Membutuhkan Token Role Admin

Auth Module

Endpoint untuk registrasi, login, dan manajemen pengguna.

POST /auth/register

Mendaftarkan pengguna baru ke dalam sistem.

Request Body (JSON)

{
  "name": "string", // Wajib (Tidak boleh kosong)
  "email": "string", // Wajib (Format email valid)
  "password": "string" // Wajib (Minimal 6 karakter)
}
POST /auth/login/user

Autentikasi untuk pengguna biasa dan mendapatkan JWT Token.

Request Body (JSON)

{
  "email": "string",
  "password": "string"
}
POST /auth/login/admin

Autentikasi khusus untuk Admin dan mendapatkan JWT Token.

Request Body (JSON)

{
  "email": "string",
  "password": "string"
}
PATCH /auth/update
Auth Required

Memperbarui profil pengguna yang sedang login (berdasarkan token).

Request Body (JSON) - Opsional

{
  "name": "string",
  "email": "string",
  "password": "string" // Min 6 karakter
}
GET /auth/users
Auth Required Admin Only

Mengambil daftar semua pengguna dengan role USER. Hanya bisa diakses oleh admin.

Booking Module

Endpoint untuk mengelola pemesanan paket wisata.

POST /booking
Auth Required

Membuat pemesanan baru. ID Pengguna (User ID) diambil otomatis dari token JWT.

Request Body (JSON)

{
  "bookingCode": "string",
  "packageId": number,
  "date": "2026-05-05T00:00:00Z", // Format Date ISO
  "quantity": number,
  "totalPrice": number
}
GET /booking/me
Auth Required

Melihat daftar semua pemesanan yang dilakukan oleh pengguna yang sedang login (berdasarkan token).

PATCH /booking/:id
Auth Required

Membatalkan pemesanan berdasarkan ID pemesanan. Hanya bisa membatalkan pesanan milik sendiri.

Path Parameter: id - ID numerik dari pemesanan.

GET /booking

Melihat daftar semua pemesanan dalam sistem.

Bookmarks Module

Endpoint untuk menyimpan paket wisata favorit (bookmark).

POST /bookmarks
Auth Required

Menambahkan paket ke daftar favorit (bookmark) pengguna. ID pengguna diambil dari token.

Request Body (JSON)

{
  "packageId": number // ID paket yang ingin di-bookmark (Wajib, minimal 1)
}
GET /bookmarks
Auth Required

Mengambil semua daftar bookmark milik pengguna yang sedang login.

DELETE /bookmarks/:id

Menghapus bookmark berdasarkan ID.

Path Parameter: id - ID bookmark yang ingin dihapus.

Packages Module

Endpoint manajemen paket wisata.

GET /packages

Menampilkan semua paket wisata yang tersedia.

GET /packages/:id

Mendapatkan detail spesifik sebuah paket wisata.

Path Parameter: id - ID paket wisata.

POST /packages

Menambahkan paket wisata baru ke sistem.

Request Body (JSON)

{
  "name": "string",
  "description": "string",
  "price": number,
  "location": "string",
  "image": "string" // URL atau nama file gambar
}
PATCH /packages/:id

Memperbarui data paket wisata yang sudah ada.

Request Body (JSON) - Opsional

{
  "name": "string",
  "description": "string",
  "price": number,
  "location": "string",
  "image": "string"
}
DELETE /packages/:id

Menghapus data paket wisata secara permanen.

Path Parameter: id - ID paket wisata.

Payments Module

Endpoint integrasi payment gateway (Midtrans).

POST /payments/midtrans/webhook
Webhook

Endpoint yang dipanggil secara otomatis oleh server Midtrans (Webhook/Notification URL) untuk memperbarui status pembayaran. Tidak untuk dipanggil manual oleh frontend.

Request Body (Format JSON Payload Midtrans)

{
  "order_id": "string", // Format misalnya: pesanan-12 (id booking = 12)
  "transaction_status": "capture" | "settlement" | etc,
  "fraud_status": "accept" | etc,
  ... (Parameter Midtrans lainnya)
}
